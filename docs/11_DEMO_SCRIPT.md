# Demo Script

The final demo should be about 90 seconds.

## Sequence

1. Engineer opens CodeCast.
2. Engineer says: “Cast, walk me through PR 1.”
3. CodeCast explains the PR diff.
4. Engineer interrupts and says: “Skip it, jump to the checkout PR.”
5. CodeCast stops speaking and switches context.
6. CodeCast identifies a missing null check.
7. Engineer says: “Post that as a comment.”
8. A real GitHub comment appears.
9. Engineer says: “Submit it as request changes.”
10. CodeCast submits a real GitHub review.
11. OpenRouter generates a written review digest.
