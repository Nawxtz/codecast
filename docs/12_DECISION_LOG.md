# Decision Log

## Decision 1: Use real GitHub writes

Reason:

Real GitHub writes are the strongest proof for the hackathon.

Constraint:

Writes must be safe, scoped, and reversible.

## Decision 2: All GitHub writes happen server-side

Reason:

The browser must not hold GitHub secrets.

## Decision 3: MVP is single demo repo

Reason:

Hackathon scope must remain tight.

## Decision 4: Dry-run is default

Reason:

Prevents accidental writes during development.
