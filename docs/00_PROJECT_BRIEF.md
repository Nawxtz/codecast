# Project Brief

CodeCast is a personal project: a voice-native GitHub pull request review copilot.

The goal is not to build a production SaaS product. The goal is to build a polished, credible demo that proves:

1. Low-latency voice interaction works.
2. Barge-in interruption works.
3. The agent can understand GitHub PR context.
4. The agent can execute real GitHub tool calls safely.
5. The demo produces real, clickable GitHub artifacts.
6. OpenRouter can generate a post-session review digest.

The winning message is:

> CodeCast is not a simulated tool-calling demo. It performs real GitHub actions during a live voice session.
